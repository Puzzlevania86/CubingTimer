# Overview

A cubing timer created in HTML, CSS, and JavaScript that runs localhost

## Features

- Creates scrambles for 3x3, 2x2, 4x4, and Skewb
- Can switch between practice and competition modes
- Allows you to run the timer with the space button and stop it with any key
- Adds the time to the list of times
- Computes ao5s and ao12s
- Allows you to go back and forth between different scrambles

## Requirements

Live Server extension to run program localhost
